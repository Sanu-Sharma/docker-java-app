# Docker Java App 🐳

Simple Java application containerized using Docker.

## 🛠️ Technologies Used
- Java 17
- Docker

## 🚀 How to Build & Run

### Build Image
```bash
docker build -t java-app .
```

### Run Container
```bash
docker run java-app
```
